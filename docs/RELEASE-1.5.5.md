# Codex Quota Badge v1.5.5

默认显示主账号额度，增加主账号／副账号展示切换

- 管理页「行为与服务 → 额度与刷新」选择展示账号，保存即生效
- 只调整额度显示，不切换 OpenCodex 账号、不改变请求路由
- 额度卡片与状态中心标明账号角色，所选账号不可用时不代用另一账号
- 主副账号历史隔离，同一重置时间也不混账；切换中的旧请求结果丢弃
- 旧未区分账号的历史文件原件保留，不猜测归属；新历史从明确账号样本开始估算
- 保留既有会话样式、两类整数归因、监测退避和 owned popup 兼容选择

普通安装包不包含 OpenCodex 网关二进制。解压到新目录后，用 PowerShell 7 执行 `./update.ps1 -TargetPath "D:\Tools\codex-quota-badge"`

支持一个主账号和一个副账号；多个副账号不猜选。主账号历史按角色隔离，替换主登录身份暂不能自动识别。读取本地缓存不增加网络轮询，保留真实更新时间；超过 15 分钟视为不可用。

验证：44 个模块、446 项回归通过；后续提醒隔离补充验证通过。

账号级本机活动缺少可靠关联时，归因采用估算先验，不把另一个账号的本机活动直接归给当前展示账号。新增相应回归通过。
