# Codex Quota Badge v1.5.6

修复主副账号隔离后本机与非本机归因停留在固定五五分的问题

- 按实际账号额度端点与本机请求估算，排除第三方渠道和未计用量失败请求
- 主账号补充身份及周窗口匹配的原生额度样本，明确账号请求不跨账号计数
- 历史缺口按同账号经验关系回推，本机日期按请求分布；没有证据不虚构固定比例
- 只显示本机、非本机两项整数，并提示估算置信度；非本机包含未获本机证据的估算余量
- 旧归因先备份后重算；保留主副账号选择、配置、历史和 owned popup 模式
- 主账号网关缓存过期时，可复用身份及唯一周窗口匹配的近期原生响应，保持真实采样时间
- 有界增量读取复用已有刷新，无新增网关补丁、网络、定时器或后台线程

这不是官方逐设备账单；缺少逐请求账号标签及早期历史时为低置信估算。算法见仓库 docs/QUOTA-ATTRIBUTION.md

普通包不含 OpenCodex 网关二进制。解压到新目录后，用 PowerShell 7 执行 ./update.ps1 -TargetPath 指向已有插件目录

验证：47个模块、521项完整回归通过；随后补充原生额度恢复等专项回归通过，发布前再次执行安装包门禁。
