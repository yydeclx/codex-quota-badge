OpenCodex 2.92 的 `/api/logs` 只提供已结束请求，不提供流中的增量 Token。此版本兼容路径会在会话仍运行时展示该回合最近已结束请求，并明确标注；无法获得的流中速度显示“未提供”。日志中的会话哈希按上游 SHA-256 截取 32 位的规则匹配，仅关联同一回合，不把历史请求冒充当前实时输出。旧版实时活动接口如提供完整字段，则仍展示实时首字与速度。

## 管理和扩展

- 右键任意展示项：刷新、开关各项、当前项上移/下移、编辑配置、退出
- `sidebar-config.json` 的 `items` 顺序即展示顺序；`enabled` 控制开关，修改后自动加载。可以全部隐藏，最多八项
- `python manage.py list/status/stop` 查看配置、运行状态或退出

- `python manage.py move skg_today 1` 将 SKG 调整至第一项
- 既有 provider 只需新增 `opencodex_today` 配置项；新的数据源通过 `sidebar_data.py` 扩展，绘制和原生窗口跟随分离
- `.codex-plugin/plugin.json` 与 `skills/sidebar-management/` 是本地 Codex 插件源码包；当前 Windows 伴随程序已运行，不代表源码包已安装到官方插件管理页

## Token 统计

- 使用已安装的 OpenCodex CLI：`ocx usage --range today --surface all --json`，只读，不读取密钥
- `openai` 显示为 ChatGPT，`SKG` 显示为 SKG；按本机 OpenCodex 的当日日界、所有 surface、provider 汇总
- 读取 `providers[].totalTokens`，缓存输入已经包含在输入中，不二次相加
- 这是本机记录的通道用量，不是 ChatGPT 账号全设备用量，也不是公司网关账单；切换账号后的日志可能仍在同一 provider 分组
- 默认每 60 秒刷新一次，两个 Token 项共用一个查询；允许配置 30–3600 秒
- 整数 K/M/B，十进制四舍五入：123456789 → 123M，999500 → 1M；悬停展示精确值、输入/输出/缓存和未上报请求数
- 失败、过期、跨天旧数据显示破折号；完整结果里无该 provider 请求时才显示零。全未上报也显示破折号，部分未上报显示已知合计并提示缺口
- `test_sidebar_data.py` 验证单位进位、缓存口径、缺失、截断和跨天；`test_sidebar_plugin.py` 验证实际绘制、悬停、开关及排序

## 窗口和资源

启动脚本通过 Windows WMI 启动无控制台的 pythonw，避免直接依赖 Codex 终端子进程；后台发现旧窗口失效后会重新查找并附着新窗口。管理页提供可选登录自启动：开启后通过当前用户 Run 启动项启动伴随程序，等待客户端窗口出现；默认关闭。

- 原生 Windows 子窗口，附着在 Codex 主窗口内；移动、遮挡和最小化由系统同步处理
- 尺寸变化使用窗口事件即时调整底部位置；每秒健康检查不承担拖动跟随
- 无全局置顶，不抢键盘焦点；背景使用用户截图核验的侧栏色 `#F3F2F0`，不使用不可靠的实时屏幕取色
- 每 5 分钟读取一次官方 `account/rateLimits/read`，只查询 10080 分钟的 Codex 周窗口
- 点击打开详情，悬停查看摘要；右键可刷新、管理或退出
- 悬停框使用独立绘制的浅色卡片：10 DIP 圆角、细灰边、轻阴影、约 98% 背景不透明度；两行展示额度与重置时间，不使用 Windows 系统 Tooltip 控件
- 鼠标停留约 250 毫秒后显示提示，移出或切换应用后隐藏；使用显式指针检测，避免跨进程子窗口的默认悬停触发失效
- 图标采用紧凑完整圆框：21 DIP 外径、1.7 DIP 灰色描边、10.5 DIP Calibri Bold 数字；三位数缩至 8 DIP
- 查询失败显示破折号，不把缺失数据当成 0% 或 100%
- 不改 Codex 安装包或账号凭据；活动状态功能使用 OpenCodex 本地补丁版；仅在用户启用自启动时管理本工具自己的 HKCU Run 启动项；不发起模型对话、不消耗重置券
- 使用本机 Codex CLI 的登录态，若切换了账号请点击刷新
- 退出后可再次运行启动脚本；客户端布局大改后可能需要调整位置

`status.json` 保存本工具进程、父子窗口关系、位置、额度和时间，用于验收，不含凭据

`test_native_badge.py` 使用独立的临时测试窗口，检查跨进程父子关系、150 次同步移动、25 次尺寸变化、隐藏和最小化恢复，以及退出不影响宿主；不会移动用户的 Codex 窗口

保留 `quota_badge.py` 与 `start-polling-backup.ps1` 作为旧版回退副本，回退前先右键退出当前显示

这是操作系统层面的子窗口，并非官方侧栏组件；客户端内部缩放或布局大改仍可能需要调整位置

接口文档：https://learn.chatgpt.com/docs/app-server


## 本地管理窗口

运行 `manage.ps1`，或右键侧栏 → 打开侧栏管理

- 展示模块：勾选、排序、逐项后方间距；可以全部隐藏，恢复时从 manage.ps1 打开
- 样式与间距：10 种共用 GDI 绘制的实际预览；数字根据实测宽度缩小，完整保留单位
- 底部留白 45–180 DIP，默认 87；数值越小越向下。靠近帮助或头像时请按当前窗口布局调节
- 统一间距按钮将数值填入各项；最后一项不使用后方间距，由底部留白控制
- 启动与运行：可选 Windows 登录待命，客户端打开后自动附着；不启动 ChatGPT/Codex 本身
- 保存并应用后约 1 秒热加载，无须重启客户端；新增 provider 共用已有用量查询
- Tk 管理窗口只在打开时运行，无 HTTP 服务或浏览器依赖，关闭窗口不影响侧栏
- 新数据源扩展在 sidebar_data.py 增加校验和适配器，在 SidebarPlugin.row_usage/update_tooltip 接入；不要把未知数据标为零

## 链路活动绿点

2026-09-29 更新：Token 卡片右上角圆点为 3.6 DIP。该链路有本机运行会话或实时在途请求时持续绿色呼吸（包括等待/工具阶段），不再仅凭最近内容增量闪烁。左上角对称位置的蓝色实心点表示该链路有已完成未读会话；二者独立，可同时显示。点击详情中的“查看会话”或在 Codex 中查看对应会话后，依据 Codex 未读记录约两秒同步清除；只打开链路详情不会批量标记已读。会话的 `SKG/model` 路由优先于通用 `model_provider=openai`，有实时关联时使用实际链路。仍受本机任务记录与未读来源的覆盖范围限制。

需要本地活动接口版 OpenCodex 2.69.0。每秒从本机受保护的 `/api/system/provider-activity` 读取 Responses 链路在途请求数，并结合本机会话记录判断运行状态。等待响应和工具执行期间，只要会话仍被识别为运行，绿点继续呼吸；结束且无其他运行会话时熄灭。并发链路可同时亮灯。绿点不保证远端模型一直在生成。

链路健康复用同一个点，适配全部 Token 样式：最近失败、未完成或 HTTP 429 显示黄点；HTTP 401/403、5 分钟内连续三次异常显示红点。主动取消不计失败，后续成功清除告警，历史告警 5 分钟后过期。活动接口连续两次连接被拒绝或发现文件不存在显示红色“未连接”；其他读取错误显示黄色“状态暂不可用”，不推断为上游鉴权问题。关闭“链路活动提示”也会隐藏健康点。

悬停卡片展示含今日的本地日历七日柱图（今日未结束），来自受保护的用量 timeline 接口，5 分钟缓存，最多读取 1 MiB；截断或过期数据不绘制。最近请求复用 usage.jsonl，每两秒检查变更，仅变更时读末尾最多 2 MiB，内存只保留各链路最近 32 条时间、耗时、HTTP 状态和结束分类，不保存正文或凭据。按 OpenCodex 的 terminalStatus/closeReason 优先于 HTTP 状态判断结束结果。等待/输出仍由实时活动接口判断，不用日志频率推测。日志范围内无记录时显示暂无记录。

活动接口使用只读进程绑定的短期 HMAC 能力凭据，不读取模型凭据和管理员令牌。后台网络超时 0.8 秒，失败退避 5 秒，状态超过 3 秒失效。最近完成请求另行读取有界日志末尾。原有 1.8 秒呼吸周期及全部样式保留，只有可见且活动的图标重绘。管理页可以关闭。

## 状态中心（本地扩展）

- 单击任意模块打开对应详情；重复点击复用详情进程，右键菜单继续管理。原配置、顺序、底部锚点和间距保留。支持最多 16 个注册模块；三个任务模块默认展示，服务和快捷入口默认隐藏。
- 运行任务读取本机只读 SQLite 最新回合（最多 300 个未归档会话），兼容外层/底层会话 ID。五分钟内有记录或实时请求关联才计运行，陈旧未结束记录列为未确认。工具阶段超过五分钟无新记录且无请求关联时无法确认。未读来自单一身份的 Codex 本地 read-state，不写入或擅自标记已读。只覆盖本机，不代表远程主机任务。
- 待处理为预览模块：已识别明确等待字段才列出；本地历史不保证记录实时审批和异步提问，因此无法确认时显示 `—`，不能将其当作零待办。目前未接入官方持续任务状态接口。
- Token 悬停只增加一行速度，展开页显示实际返回/路由模型、推理档位、重试次数、最近请求和连接异常。解码速度为 outputTokens / (durationMs - firstOutputMs) 的估算值，窗口至少 1 秒，缺字段不补值。短期 HMAC 接口 schema 3 在途列表最多 128 项，不含内容和凭据。请求 UUID 能对应会话时提供跳转。
- 连接异常/恢复最多保留 20 条到 `connection-history.json`。诊断复制使用显式字段白名单，不包含正文、密钥、完整原始日志和会话路径。
- 诊断页显示套餐、额度/用量读取状态、GPT 活动来源、完整边界采样、未分配下降和插件版本；只读取脱敏本地快照。
- GPT 开始、结束及连续运行每 10 分钟执行完整边界采样。周额度和本机 GPT 用量在同一事务完成后入库；周期轮询不会归入本机。下降量分为本机活动期间与其他/未分配，SKG、OCX 活动不触发额度边界采样。
- `quota-history.json` 保留最近八个观察到的周期。每日消耗是两次相邻采样差值，采样间隔最多 15 分钟且必须同一天；跨日/离线差值记入未分配。第一次观测之前不回填，不将未知日填零，额度上调记录为校正。不是官方逐日账单。
- 服务仅检查本机配置端口是否可连接（不等于业务健康）；管理中可添加/移除服务和目录入口。服务最多 8 项，入口最多 12 项。仅保存到本地配置，端口检查后台执行，不启动或重启服务。
- 详情每两秒刷新本地快照；任务/服务每五秒检查，趋势五分钟缓存。无浏览器运行时、无模型调用、无新依赖。新增窗口按需启动。

OpenCodex 官方更新可能覆盖本地接口版；此时会显示状态不可用，需要针对新版本重新适配。不会退回成误导的日志活动提示。


## 外观更新（2026-09-29）
