# Codex Quota Badge v1.5.1

Windows owned popup 兼容模式升级到 v1.5.0 后，旧布局忽略水平偏移，并沿用 34 DIP 窗口宽度，导致 Token 右边框被裁切。v1.5.1 正式纳入兼容入口和模式选择，保留已验证的 owned popup 机制。

- 子窗口与 popup 共用包含两侧留白的布局，支持正负水平偏移和动态行高；popup 在客户区计算后转换为屏幕坐标
- ClientToScreen / SetWindowPos 失败时不更新布局缓存、计数或请求重绘，由既有刷新机制重试
- 悬停接受宿主或徽章自身根窗口；popup 不运行仅适用于子窗口的层级修复，不启用全局置顶
- 默认仍使用透明子窗口；显式选择保存在本机 window-mode.json
- 安全更新在覆盖前迁移旧监督器中静态指向 sidebar_compat.py 的入口；已有模式文件优先，配置、账号状态、历史与已有网关附件保持本机内容
- 补齐安装包、升级文件清单和自动更新入口；部署失败恢复程序与本次迁移，等待旧监督器退出后再启动

本版不更改 Token、周额度和相关会话样式，不添加计时器、忙循环或高频日志，不携带新的网关二进制。

## 升级

将普通包解压到新目录，使用 PowerShell 7 执行：

```powershell
.\update.ps1 -TargetPath "D:\Tools\codex-quota-badge"
```

请使用更新脚本，不要直接覆盖旧目录。兼容模式也可显式选择：`python .\window_mode.py --set owned-popup`，仅需重启侧栏；切回默认方式使用 `--set child`。详见 PORTABLE-INSTALL.md。

本次验证在隔离测试和本机创建的离屏 Win32 测试窗口完成；目标电脑 D:\Tools\codex-quota-badge 的升级和真实客户端目视验收需在该电脑执行。
