# Codex Quota Badge v1.5.4

修复周额度变成横杠，以及网络临时失败后重置监测长时间过期的问题

- 兼容 OpenCodex provider quota 报告中 aggregation 位于 quota 同级或内部两种结构
- 优先读取完整的当前账号观测；缺失时使用完整的账号池观测，不混合账号池百分比与单账号重置时间
- 观测时间优先使用对应数据自身的时间戳，支持秒及毫秒；5 小时窗口仅取同一口径且完整的观测
- 重置监测失败按 60、120、240、480、900 秒退避，成功后恢复 15 分钟周期；复用现有心跳，保留最后有效缓存
- 保留 v1.5.3 两来源整数归因、会话行样式、owned popup 选择及全部个人配置

普通包更新只需重载侧栏，不重启 Codex、OpenCodex 或 Clash，不包含网关二进制

将普通包解压到新目录，使用 PowerShell 7 执行 `./update.ps1 -TargetPath "D:\Tools\codex-quota-badge"`

验证：40 个模块、404 项回归通过（原生 GUI 模块逐进程隔离），包括新旧报告格式、账号/池口径隔离、缓存保护、退避上限和通知丢失恢复
