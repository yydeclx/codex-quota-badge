# Codex Quota Badge v1.5.2

v1.5.1 基于 v1.5.0 发布兼容修复时，遗漏了后来已确认并在开发电脑运行的会话样式和额度恢复修改。v1.5.2 将这些修改纳入正式源码及普通安装包，保留 v1.5.1 的全部 Windows owned popup 兼容修复。

- 底部会话单行显示：标题左侧，来源/模型胶囊右侧，保留完整来源前缀
- 会话标题加大加粗，胶囊带轻微边框与阴影；宽度 280 DIP，最终行高 30 DIP
- 米白实底、浅灰悬停、等距留白，长标题优先省略；悬停不改变尺寸和点击命中区
- 额度读取失败使用现有心跳按 5、10、20、40、80、160、300 秒退避，成功后清除失败状态并恢复正常刷新；仅记录错误类型
- 保留默认子窗口和可选 owned popup、正负水平偏移、完整画布、悬停及模式迁移
- 配置、账号状态、历史和模式选择继续保留；不增加计时器、额外常驻进程或网关附件

## 升级

将普通包解压到新目录，使用 PowerShell 7 执行：

```powershell
.\update.ps1 -TargetPath "D:\Tools\codex-quota-badge"
```

使用更新脚本，不要直接覆盖旧目录。更新后的侧栏需重新加载，另一台电脑的实际升级验收由该电脑执行。

## 验证

37 个测试模块、347 项完整回归通过，覆盖新样式、点击命中区、来源前缀、额度恢复及 popup 布局和升级回滚。初次受限环境无法读取系统 Tcl/WMI 的六组测试已在允许这些系统读取的环境复核通过。

发布前逐项核对本机与已发布基线的代码差异；会话绘制器与已验收本机实现逐字节相同，v1.5.1 的兼容入口、监督器选择、模式文件和升级迁移逻辑保留。安装包完整性与远端下载文件在发布时再次校验。
