# Codex Quota Badge v1.5.3

- 无证据时使用平滑先验，完全无历史从各半开始；长断档不全归当前会话

- 两色堆叠柱状图、每日悬停、图例和状态中心统一使用整数百分比，注明归因估算
- schema6 迁移前保留原始历史备份，重复加载不重复迁移；退款、重置抖动及乱序防护保留
- 不增加网络请求、计时器、线程或高频日志；保留 v1.5.2 的单行会话样式及 popup 兼容修复

官方只提供总量，分设备及断档日期均可能包含估算，不代表官方逐设备账单。详见 docs/QUOTA-ATTRIBUTION.md。
