# 周额度的本机与非本机归因

官方周额度是总量，插件不能直接读取官方逐设备账单。所有分设备结果均为估算，界面只保留本机、非本机两项。

1. 周期净消耗始终以 `100 - 官方剩余额度` 为准
2. 同一周期、15 分钟内有新鲜的本机用量增长、本机活动或待结算证据，优先计入本机；同日累计用量在两次新鲜快照间完全不变且无本机活动证据，计入非本机
3. 证据不足时使用平滑历史比例：本机份额 `(已归本机 + 1)/(已归本机 + 已归非本机 + 2)`。完全没有历史时为各半，不把读取异常当成全部非本机
4. 长断档中只有当前本机活动证据时，活动覆盖权重为 `min(1, 900/断档秒数)`；其余按历史比例分配，避免把几小时消耗全部算给当前会话
5. 初次采样前的缺口按重置至首次采样的时间段分配，跨日缺口按各日本地时间的实际秒数分摊；日期缺失的旧记录也估算分配到周期内
6. 回调/返还先从最新日期扣减，并按该日两类来源的比例减少；新周期不借用上周期的用量，120 秒以内的重置时间抖动保留同一周期
7. 账本用万分之一百分点单位闭合；显示统一为整数百分比，对每日与来源一起舍入，保证日、来源、周期显示总量一致

schema6 迁移保留原始备份。已明确归因的历史优先保留；原来的待定部分按上述先验估算分摊，存储及界面不再有第三个来源或日期待定项。算法不添加网络请求、计时器、后台线程或高频日志。

当多台设备同时运行、用量日志延迟或长时间未采样时，估算可能偏离真实逐设备消费。缺少观测时的先验与按时间分配是一种明确的默认假设，不能反推精确发生时间，也不能据此判断账号是否被他人使用。
