# Codex Quota Badge v1.5.0

## 本次更新

- 保留当前已部署界面，不包含本轮讨论的设计示意方案
- 修复周额度每日总量、来源堆叠和悬停明细不一致；能确定日期的首采缺口归入对应日期，设备来源无法确认时保留“来源待定”
- 处理跨日、额度回补、重置时间抖动、陈旧采样和来源估算边界，避免重复计量或把未知消耗强行归为本机/非本机
- 管理页和状态中心统一标题、版本胶囊、文字与间距；修复闪动、滚动条、负间距设置及悬停显示问题
- 改善后台退避、绘图缓存、有界日志读取、进程清理和故障自恢复，减少无效工作
- 补齐安装及更新依赖；校验版本一致性、干净环境导入和发布文件白名单，普通更新保留每台设备自己的设置、历史和已有补丁

## 下载与更新

- 普通安装包：`codex-quota-badge-1.5.0.zip`，包含当前完整侧栏程序和安装文档
- 可选网关附件：`opencodex-telemetry-2.92.0-1.5.0.zip`，仅适配 Windows x64 OpenCodex 2.92.0；解压到侧栏目录，再在管理页显式开启。包含原版回滚程序、补丁程序和对应 MIT 许可证
- 普通安装与更新不自动应用网关补丁；新装默认关闭实时指标补丁，已有安装保留原设置。切换补丁可能重启网关，忙碌或版本不符时拒绝切换
- 使用 PowerShell 7 执行 `update.ps1 -TargetPath <原安装目录>`；自动更新器只选择普通侧栏安装包
- 附件 SHA-256 见 `SHA256SUMS-1.5.0.txt`

本机/非本机额度来自本地采样估算，并非官方逐设备账单。OpenCodex 官方更新后，2.92.0 补丁需要重新适配
