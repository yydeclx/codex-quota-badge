# 输入框内嵌原型

从仓库根目录运行 python prototypes/composer-inline/build_preview.py 新的HTML路径，生成可直接用浏览器打开的单文件预览。用左侧按钮切换新聊天、已有会话、分屏和文件全屏，右上角开关可以撤下底栏。会话 B 故意晚返回，用来验证快速切走后不会串数据。

底栏由工具栏自身排版居中。宿主明确提供主工具栏的位置和当前会话 ID；辅助输入框不挂载。

Windows 客户端测试：从仓库根目录执行 python prototypes/composer-inline/run_codex_test.py --exe 已安装的ChatGPT.exe完整路径 --test-dir 新的测试目录。脚本启动独立的 Codex 实例，使用新建的客户端资料目录和 Codex 数据目录，通过继承的本机管道把组件挂进测试窗口。测试窗口需要单独登录。默认实例、安装文件及现有浮层设置不会被替换。

测试目录中的 status.json 记录连接、挂载、底栏是否居中和文字是否被截断，以及是否识别到会话 ID，不写入 ID 本身。创建同目录的空文件 disable 可以撤下内嵌底栏，删除该文件会恢复；创建空文件 reload 可以在测试窗口重载原型；创建空文件 stop 会关闭测试实例。也可以直接关闭测试窗口。关闭后删除 stop，使用原测试目录并加 --resume 可复用该测试资料。测试用量从该实例自己的本机记录读取，尚未接入速度遥测。

可选：从仓库根目录运行 python prototypes/composer-inline/read_view.py 会话ID 新的本机JSON路径，再在预览中打开导出的文件。导出复用现有用量读取和计算，只输出该会话的用量字段和 ID，没有标题或消息。预览在本机读取文件，不上传。该文件是快照，实时更新需要实际宿主提供数据。
