# 输入框内嵌验证版（基于 1.5.9）

「Codex（内嵌底栏）」开始菜单快捷方式已撤下。此目录保留本地验证原型，它需要由启动器从冷启动建立私有本机管道；不能挂接已经通过 Windows 原入口运行的客户端。主 Codex 原入口继续使用已安装的侧栏浮层，安装包和会话资料不变。

底栏挂在主会话输入框工具栏，沿用原版的会话用量计算。卡片由客户端直接排版，贴着底栏居中；窗口过小时在卡片内滚动。英文和数字优先使用本机 Poppins，中文优先使用本机 MiSans，各自在缺失时回退到微软雅黑。不会下载字体。鼠标悬停展开，点击固定，再点击或按 Esc 收起；卡片保留逐轮统计、滚轮翻阅和返回。

托管启动时，侧栏管理的「会话用量」控制底栏显示；「会话状态指示」只影响圆点，「实时指标补丁」独立控制运行中的指标读取。底栏样式和字重从侧栏设置读取。只给已挂载的内嵌底栏续期，浮层在内嵌不可用且满足自身显示条件时可以接回。

在 Windows 文件资源管理器里双击 `Start-Inline-Validation.cmd`，会打开独立的 PowerShell 7 窗口。验证期间请保留这个窗口。启动器等待主 Codex 正常退出（最多 10 分钟），再使用原账号和本地资料自动打开。退出前请等任务结束并保存草稿，不用手动打开第二次。安装包不改动，连接使用本机继承的私有管道，不开调试端口。

新版成功挂载后，暂时关闭旧版的「会话用量」浮层，避免重复展示；其他侧栏项目照常运行。退出验证中的 Codex 后会恢复旧开关。如果 Python 启动器提前退出，外部 PowerShell 窗口会再尝试恢复一次。也可用 PowerShell 7 运行 `./composer-inline-validation/switch.ps1 -Restore` 停用或恢复异常退出留下的记录。

状态文件在 `%LOCALAPPDATA%/CodexComposerInlineValidation/status.json`，只记录挂载状态、是否识别到会话和卡片打开状态，不记录会话 ID 或内容。验证窗口为一次性启用，之后正常启动 Codex 会回到旧版。
